Origins Classic UI for Lets Together / NeoOrigins 2.2.29
Panel adapted from Origins Fabric (apace100, MIT license):
https://github.com/apace100/origins-fabric/tree/1.20
Source assets: textures/gui/sprites/choose_origin/*.png (frame, name plate, impact, scrollbar)
Original license: origins-fabric.txt (in this directory).
The fixed selector uses original-size Origins sprites and vanilla Minecraft buttons.
The separate info-page theme uses an adapted gold name plate and gray buttons generated by ui_theme.py.
Uses minecraft:default; no additional font is redistributed.
The four parchment/scroll_* textures replace NeoOrigins shared button art.
These replacements also apply if another textured NeoOrigins theme is selected.
