# 村民反击！

:entity[minecraft:villager] 会记住每位玩家如何对待自己。交谈、交易、礼物、任务、目击的罪行、村庄事件、战斗、工作和时间都会影响这些关系。本指南介绍模组内置的 **1.0.0-beta.13 预览版**内容。

:::notice{type="info"}
本指南描述默认设置。服务器可以修改费用、门槛、时间和功能，数据包也可以替换任务、对白、礼物等内容。请以游戏中显示的数值为准。
:::

:::notice{type="warning"}
测试 beta.13 前请备份存档。客户端会在首次创建世界或进入多人游戏前显示一次持续三秒的提示，选择**我已了解**即可继续。
:::

## 第一步

:::steps
:::step{title="结识村民"}
主手空手右键成年村民即可打开互动界面。默认情况下，潜行并右键可跳过此界面，使用原版互动。
:::
:::step{title="留下好印象"}
交谈、交易、帮忙和治疗；避免伤害村民或拿走受监视容器中的物品。
:::
:::step{title="了解村民"}
挑选合适的礼物，查看村民的技能和档案，再寻找适合他们的任务或工作。
:::
:::step{title="使用任务日志"}
按 :key[key.villagerretaliation.open_quest_journal] 打开任务日志，按 :key[key.villagerretaliation.toggle_quest_tracker] 切换任务追踪器。
:::
:::

## 核心要点

> 把每位村民当作独立的个体。他们的职业、技能、性格、心情、记忆、家园，以及对**你**的看法，都可能影响互动。

良好的往来会改善对白、价格、礼物、任务、雇佣条件和村庄待遇。伤害、偷窃、背叛和公开施暴则可能通过目击者传播，导致拒绝服务、逃跑或反击。
