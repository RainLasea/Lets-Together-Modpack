# 售货箱与每日市场

用木桶和服务器货币标签中的物品合成 :item[villagerretaliation:sell_box]。必须放在**村庄内**：位于所有已记录或可识别村庄之外的售货箱无法报价，也不能接受出售。

:::steps
:::step{title="放入可出售物品"}
打开箱子，在待售槽中放入一组物品。界面会显示当前精确价值。
:::
:::step{title="确认出售"}
选择**出售**。这组物品会被消耗，其精确价值计入箱子保存的余额。
:::
:::step{title="提取收入"}
选择**提取**。整数部分的货币物品进入你的物品栏，零头留在余额中，与以后的收入累积。
:::
:::

:::

## 当地价格

每个村庄都有独立的每日市场。同一种物品在不同村庄或不同 Minecraft 日的售价可能不同。同一需求类别中的物品会一起涨跌。

出售会增加当地供给压力。在同村反复出售，会逐渐降低该类别之后的收入；供给压力会在后续几天恢复。请以售货箱界面的精确报价为准。

:::notice{type="info"}
服务器数据包决定哪些物品可以出售及其基础价格范围。配置为货币的物品不能出售。
:::

## 工人与自动化

- 分配为**产出**仓储，工人可以存入可出售的产物。
- 分配为**原料**仓储，搬运工可以取走整数部分的货币收入。
- 漏斗和物品处理接口从顶部或侧面放入待售物品。
- 漏斗和物品处理接口从底部取走可提取的整数货币。
- 用另一组有效物品替换已占用的待售槽时，会先出售原来那组物品。

拆下箱子时会保留待售物品和精确余额。售货箱属于公共自动化仓储，并非安全的个人保险箱。
