# 任务

可接任务取决于当前玩家、村民和世界的状态。模组内置某个任务，并不意味着每位村民都能提供它。

## 如何完成任务

1. 与正确且有空的村民交谈。
2. 阅读职业、交易等级、技能、声望、前置条件和重复接取要求。
3. 按 :key[key.villagerretaliation.open_quest_journal] 打开日志。
4. 按 :key[key.villagerretaliation.toggle_quest_tracker] 切换实时目标显示。
5. 完成所有目标，再带上规定的证明物品和需消耗的物品，返回指定委托人处。

任务可以包含坐标追踪、任务物品高亮、HUD 通知、编排的场景、选择、互斥分支、冷却、受保护角色、遭遇战，以及结构或维度要求。

:::details{id="missing-quest" title="为什么无法接取任务"}
- 村民的职业、交易等级或隐藏技能分数不符合要求。
- 你的个人声望不在任务允许的范围内。
- 前置条件、先前分支选择、冷却、地点或当前任务状态不符合要求。
- 委托人正在战斗、受控制、恢复、倒地，或因其他原因无法互动。
- 服务器的数据包添加、替换或移除了内置内容。
:::

:::spoiler{label="任务排查提示"}
如果进度似乎卡住，请仔细阅读当前追踪目标：确认需要的是携带物品、交付时上交物品、到达目标地点、击败特定实体，还是返回最初的委托人。
:::

## 每日任务板

内置任务板委托每个 Minecraft 日按村庄分别轮换。一个村庄最多显示三个当前符合条件的任务；候选任务足够时，会避开前两轮的内容，并限制战斗、远途、探险、困难或极难任务同时出现的数量。其他村庄可能有不同的任务板；不属于任务板的剧情任务保持原本的开放条件。

完成任务可以获得经验、个人声望和流言声望、战利品、故事信息，以及后续任务的接取资格。
