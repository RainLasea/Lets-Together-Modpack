# 操作与配置

## 默认操作

- 任务日志：:key[key.villagerretaliation.open_quest_journal]
- 任务追踪器：:key[key.villagerretaliation.toggle_quest_tracker]
- 队伍快捷命令：:key[key.villagerretaliation.quick_command]
- 蓝图放置锁定：:key[key.villagerretaliation.toggle_blueprint_placement_lock]，默认未绑定。
- 切换村民姓名标签：:key[key.villagerretaliation.toggle_villager_name_tags]，默认未绑定。
- 跳过互动界面：默认潜行 + :key[use]。

打开 Minecraft 的**模组**菜单，选择 **Villager Retaliation**，进入配置界面。多人游戏中的玩法规则由服务器决定；受支持的显示与按键偏好保存在客户端。

服务器控制合同、工资、工作限制、声望、战斗、袭击、恢复、礼物、任务、社交规则和数据包内容。客户端设置包括按键绑定、姓名标签、HUD 位置、表现方式及其他受支持的视觉效果。

:::notice{type="info"}
如果本指南中的价格、门槛、时长、任务或礼物与你所在服务器不同，请以游戏内信息为准。服务器配置和数据包可以主动覆盖内置默认值。
:::
