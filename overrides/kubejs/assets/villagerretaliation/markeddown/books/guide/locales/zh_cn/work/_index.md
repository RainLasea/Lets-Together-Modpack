# 雇佣工作

成年村民可以签订付费合同来完成实际工作。雇佣工作与[队伍招募](../party/_index.md)独立，同一位村民不能同时被雇佣和招募。

1. 查看**工作属性**，比较各岗位的资质和表现。
2. 在互动界面购买 1–30 天的合同。
3. 使用 :item[villagerretaliation:clipboard] 分配工作区域或路线，以及必需的仓储。
4. 提供工具、工作站、原料和产出空间。
5. 工作停止时，查看工人的当前状态。

继续阅读[雇佣与合同](hiring.md)、[工作夹板与仓储](clipboard-storage.md)、[工作](jobs.md)或[建筑工与蓝图](builder.md)。
