# 互动与对话

**主手空手**右键附近的成年 :entity[minecraft:villager] 即可打开互动界面。默认情况下，潜行并右键会跳过此界面，使用原版互动。

## 可以进行的互动

- 聊问候、故事、家庭、当地事件、家园以及彼此的关系。
- 送礼、原版交易，以及满足条件时的特殊订单。
- 接受任务、听取提醒、作出选择、交付任务或放弃任务。
- 拥有相应权限时，可以雇佣、管理工作、查看物品栏、安排建筑、招募、管理队伍和坐骑。

## 为什么某个选项没有出现

村民可能不满足职业、交易等级、隐藏技能或声望要求，也可能受前置条件或冷却限制。目前被雇佣、被招募、睡觉、战斗、恢复、倒地、距离过远或受其他玩家指挥的村民，也可能无法进行某些互动。

:::details{id="dialogue-context" title="对话会记住什么"}
对白会根据个人声望、职业、家庭、社交属性、心情、最近的村庄事件、初次见面、分别时长、天气、装备、附近危险、故事和任务经历作出变化。

村民会依据当前情境选择不同说法。某些台词只出现一次，或按玩家、村民、村庄、维度、世界分别记录持久冷却，因此重复互动不一定会得到相同回答。

这些系统各有作用：**声望**记录长期关系，**流言**传播目击信息，**心情**是暂时状态，**村庄归属**决定村民属于哪个社区。
:::

:::notice{type="warning"}
憎恶你、与你敌对或处于倒地状态的村民可能拒绝正常交谈或交易。某些受控状态也会主动禁用原版交易。
:::
