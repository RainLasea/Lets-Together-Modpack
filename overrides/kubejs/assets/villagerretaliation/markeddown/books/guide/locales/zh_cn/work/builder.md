# 建筑工与蓝图

建筑工承担付费的一次性工程，不是按日工作的岗位。任意成年村民都可接单，砌筑和制作技能决定资质。结构必须在服务器目录中，施工地点也必须通过检查。

:::steps
:::step{title="选择结构"}
互动界面会创建待确认的 :item[villagerretaliation:construction_blueprint]，显示尺寸、所需材料和货币报价。
:::
:::step{title="放置预览"}
右键方块移动预览。滚轮移动；按住 Alt 横移、Shift 调整高度、Alt+Shift 旋转。放置锁定按键默认未绑定。
:::
:::step{title="提供全部方块"}
建筑工使用携带或已分配仓储中的材料，并报告缺少的物品。
:::
:::step{title="保持工地可达"}
建筑工会走到每个目标位置，并遵守障碍、边界、保护规则、实体、地基和寻路限制。
:::
:::step{title="完成或取消"}
所有计划方块放置完成，或按退款规则取消项目后，订单结束。
:::
:::

将建筑蓝图与普通书以任意排列合成，即可制作 :item[villagerretaliation:blueprint_checklist]，蓝图会返还。打开清单可查看每种材料、物品图标和最近统计的数量。物品栏中达到所需数量时，对应条目会保持勾选；也可手动切换任意复选框。Shift+右键容器可统计其完整物品栏，包括大箱子的两半。

默认上限为 **4096 个计划方块**，建筑工与工地间距 **28 格**，材料仓储搜索半径 **32 格**。默认费用为 8 个货币物品，每 64 个计划方块再加 3 个。内置货币是绿宝石，请以最终报价为准。

放置任何方块前取消，会退回全部建筑工费用。开始放置后，付款将结算，在项目处理完毕前村民不能换岗。

:::notice{type="warning"}
蓝图不能记录任意建筑或导入通用投影文件。建筑工不会凭空产生材料、强制加载工地或绕过受保护的方块。
:::
