# 雇佣与合同

通过成年村民的互动界面即可雇佣。无论职业或初始技能，每位成年人都能承担任意普通岗位。傻子工作仅限傻子；建筑工使用独立的工程订单。技能决定村民完成所选工作的效率。

## 价格与期限

- 普通工作预付 **1–30 个 Minecraft 日**的费用。
- 默认基础工资为**每天 12 个绿宝石**，经技能和声望调整后，默认限制在 **4–128** 个范围内。
- 服务器可以换用其他货币，请以游戏显示的物品和数量为准。
- 开始工作前需付清所选期限的费用。
- 普通工人在合同生效期间可以换岗，无需另买合同。
- 建筑工按项目单独报价。

:::notice{type="info"}
请以确认界面显示的价格为准。服务器可以修改所有工资和期限数值。
:::

## 自动续约

:::steps
:::step{title="放置薪资箱并存入工资"}
合成 :item[villagerretaliation:payment_box]，放入配置的货币。它有 27 个槽位，用于支付工资，并非安全保险箱。
:::
:::step{title="分配薪资箱"}
将 :item[villagerretaliation:clipboard] 切换到**薪资**模式，先对箱子使用，再对雇佣村民使用。
:::
:::step{title="启用定期支付"}
已付期限结束后，工人会尝试再续约一天。
:::
:::step{title="处理欠薪警告"}
续约失败时，工作暂停并进入一天宽限期。请在宽限期结束前恢复或补充所分配的薪资箱。
:::
:::

:::recipe{id="villagerretaliation:payment_box" align="left"}
:::

提前取消会按可配置比例退回未使用的预付款，默认 **50%**。未归还的工作物品可由原指挥者在三个 Minecraft 日内领回。仅有雇佣合同**不会**赋予倒地保护。
