# 工作夹板与仓储

对空气使用 :item[villagerretaliation:clipboard] 打开工人管理面板，可以查看雇佣村民、工作、警告、工资、剩余时间、仓储、薪资、工作区域、路线、目标和最近的诊断信息。

## 分配模式

- **通用：**备用原料和归还的合同物品。
- **原料：**工具、武器、弹药、梯子、工作装备、配方原料、燃料、种子、繁殖食物、原材料，以及搬运工取货点。
- **产出：**制成品、渔获、掉落物和搬运工送货点。
- **薪资：**用于续约的薪资箱。
- **预览工作区域／设置工作区域：**查看或提交三维工作区域。
- **路线：**用于战斗、狩猎或搬运工作的有序节点。

Ctrl+滚轮可切换仓储用途。工作夹板最多选择八个容器。潜行并对空气使用可清空当前选择。

## 工作区域与路线

右键放置区域或重新确定中心。滚轮移动；按住 Shift 调整高度、Ctrl 调整水平尺寸、Alt 横移、Ctrl+Alt 调整垂直尺寸。Shift+左键清空草稿。

路线模式中，右键方块添加节点，再次使用第一个节点切换闭环；Shift+右键节点移除该节点，Shift+右键空气清空草稿。

:::notice{type="warning"}
分配与维度绑定。工作不会绕过未加载区块、墙、世界边界、保护规则、已满物品栏、限制性过滤器或无法接近的容器面。
:::

## 物品栏与过滤器

有权限的玩家可以查看独立的个人、工作和队伍物品栏。工作物品栏包含当前装备、27 格物品区、9 格快捷栏，以及 :item[villagerretaliation:item_filter] 槽位。

- **允许列表：**只处理列出的物品。
- **拒绝列表：**跳过列出的物品。

使用 :item[villagerretaliation:attribute_filter] 查看参考物品，并选择标签、创造模式物品组、燃料属性、配方用途、附魔、颜色、名称或容器状态等属性。属性过滤器可以直接放入村民过滤槽，或产出容器上的物品展示框。

物品过滤器中的普通物品为备选项，而每个嵌套过滤器都是必需条件。属性过滤器添加属性限制；嵌套物品过滤器提供其完整的允许或拒绝结果，因此可以组合允许列表和拒绝列表。最多嵌套八层。例如，过滤器包含木镐、“是熔炉燃料”和“不可堆叠”时，只接受同时满足这两项属性的木镐。药水条目会保留准确的药水内容，不会匹配所有相同瓶型的药水。评估全部限制后，再应用最外层物品过滤器的模式。

过滤器只缩小已有工作范围，不会增加配方、目标或仓储行为。

:::details{id="worker-troubleshooting" title="工人排查顺序" open="true"}
1. 检查**启用工作**和付款。
2. 检查区域或路线是否已提交、已加载且可达。
3. 检查所需的具体工具、工作站、弹药、燃料或材料。
4. 检查原料、产出、通用和薪资分配。
5. 检查容量、过滤器及不兼容的工作站内容。
:::
