# 工作

大多数岗位需要已提交的工作区域、可达的工具或工作站、原料和产出空间。战斗、狩猎和搬运可以使用路线。傻子工作不需要区域；建筑工使用蓝图工地。

:::details{id="combat-hunting" title="战斗与狩猎"}
- **战斗：**武器匠，或护卫 + 箭术。守卫保护区域或路线，巡逻则寻找自然生成的敌对生物。
- **狩猎：**制箭师，或箭术 + 生存。猎杀配置的动物、敌对生物或玩家，并收集掉落物。允许攻击玩家会带来真实的 PvP 风险。
:::

:::details{id="gathering-jobs" title="采矿、伐木、农业与钓鱼"}
- **采矿：**工具匠，或采矿 + 砌筑。需要区域和镐，支持挖掘暴露的矿石及水平、垂直开挖。
- **伐木：**采集 + 制作。需要区域和斧；配置允许且有物资时，可以补种并清理树叶。
- **农业：**农民，或农业 + 采集。需要锄、种子，以及区域或已认领的农民工作地点。
- **钓鱼：**渔夫，或钓鱼 + 生存。需要区域、钓鱼竿和能接近的开阔水域。
:::

:::details{id="processing-jobs" title="酿造、烹饪与冶炼"}
- **酿造：**牧师，或医术 + 学术。使用酿造台、瓶子、原料和烈焰粉完成支持的订单。
- **厨师：**屠夫，或烹饪 + 采集。使用熔炉或烟熏炉，部分支持的食物还需要工作台。
- **冶炼工：**盔甲匠，或锻造 + 采矿。使用熔炉或高炉进行支持的矿石加工。

这些岗位自动生产受支持的产物，并非能处理任意配方的机器。技能不会缩短原版工作站的加工计时。
:::

:::details{id="specialized-jobs" title="驯养、搬运、傻子与建筑工"}
- **驯养：**牧羊人或皮匠，或驯养 + 农业。繁殖配置的动物并收集产物。
- **搬运工：**任意成年村民。需要可用路线及输入、产出仓储。
- **傻子：**仅限傻子。偶尔生成趣味工作报告。
- **建筑工：**石匠，或砌筑 + 制作。承担单独付费的一次性工程。
:::

启用成长后，可衡量的成功工作按 70/30 比例训练岗位的主技能和辅助技能。特殊情况见[技能、属性与照料](../life/skills-care.md)或[建筑工与蓝图](builder.md)。
