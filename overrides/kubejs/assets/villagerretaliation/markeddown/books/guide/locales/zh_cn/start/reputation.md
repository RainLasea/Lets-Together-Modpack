# 声望

每位村民会分别记录与每位玩家的声望。同村的两位村民也可能对你有截然不同的看法。直接经历、目击者、流言、长期记忆，以及可选的声望衰减都会影响声望。

## 默认等级

- **贵宾：**1000 及以上。
- **敬仰：**400 及以上。
- **尊重：**250 及以上。
- **信任：**75 及以上。
- **中立：**-74 至 74。
- **怀疑：**-75 及以下。
- **敌对：**-100 及以下。
- **憎恶：**-400 及以下。
- **畏惧：**-1000 及以下。

服务器可以修改所有门槛。低声望会影响价格和对白，阻止服务或任务，延长愤怒状态，提高安抚难度，并可能导致逃跑或攻击。短暂的战斗怒气消退后，长期声望损失仍可能保留。

## 重新赢得信任

- 与仍愿意交易的村民做生意。
- 赠送他们喜欢或喜爱的礼物，避免反复刷同一种物品。
- 治疗或救助村民，抵御真正威胁村庄的敌人。
- 完成任务并满足交付要求。
- 停止打开受监视的财物，让怀疑逐渐消退。

## 安抚

只有声望等级和服务器规则允许时，敌对村民才会接受数据包定义的赔偿。内置费用为 **3–32** 个 :item[minecraft:emerald]。

:::notice{type="danger"}
安抚不会抹去过往。即使眼前的敌意已经消退，严重的个人恩怨仍可能保留；最低声望等级的村民可能完全拒绝和平选项。
:::

阅读[受监视的财物](../social/watched-property.md)，了解如何避免意外损失声望。
