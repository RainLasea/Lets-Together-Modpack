## About the Modpack

**Let's Together** is built around a simple idea: a modpack should feel like **one cohesive game**, not a collection of disconnected mods.

We carefully integrate content and mechanics to reduce fragmentation and create a smooth, consistent experience. Whether you're setting out on an adventure or settling down to build a home, the goal is to make every moment feel naturally connected — especially when playing with friends.

## Declaration

**This repository contains the open-source files for the Let's Together modpack.**

To provide a more fully integrated experience, the modpack may make extensive use of [Hotai](https://github.com/friendlyhj/Hotai) to customize or integrate mods.

This is not intended to interfere with mod creators' distribution or earnings. If you're a creator and have concerns about how your work is used here, please contact the maintainers through this repository.
